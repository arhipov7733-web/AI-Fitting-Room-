# AI Fitting Room v0.6

Android-приложение для виртуальной примерки одежды на взрослых людях.

## Что добавлено в v0.6
- системный выбор фотографии Android;
- предпросмотр исходного фото;
- выбор одного из шести образов и дополнительный текст;
- настройка denoising strength;
- подготовка изображения: масштабирование с сохранением пропорций, перекодирование в WebP/Base64;
- отправка запроса на AI Horde `/api/v2/generate/async` в режиме `img2img`;
- опрос `/api/v2/generate/status/{id}` с ожиданием до 6 минут;
- показ результата и сохранение в Pictures/AI Fitting Room;
- поле для личного AI Horde API-ключа; анонимный ключ остаётся вариантом по умолчанию.

## Сборка
Откройте папку проекта в Android Studio (или импортируйте её как Gradle project), дождитесь синхронизации Gradle и соберите `app` → `Build APK(s)`.

Требования: Android Gradle Plugin 8.7.3, Kotlin 2.0.21, JDK 17, Android SDK 35. Минимальная версия Android — 10 (API 29).

## Важные ограничения
- В этом окружении нет Android SDK/Gradle, поэтому APK здесь не собран и компиляция на устройстве не подтверждена.
- Лимит 10 в интерфейсе действует в рамках текущего запуска приложения, это не серверный дневной лимит.
- Анонимные задания AI Horde имеют низкий приоритет и время ожидания зависит от доступных работников.
- Для релиза нельзя вшивать личный секретный ключ в APK; нужен серверный прокси.
- Приложение предназначено для примерки одежды на взрослых людях с их согласием. Оно не должно использоваться для снятия одежды или создания наготы реальных людей.

## API
Официальная документация AI Horde описывает `source_image`, `source_processing: img2img` и `denoising_strength` в параметрах запроса. См. https://aihorde.net/docs/image/learn/img2img/ и https://horde.stablehorde.net/docs/image/settings/img2img/.


## Сборка APK через GitHub Actions
1. Создай пустой репозиторий на GitHub.
2. Загрузи в него содержимое этой папки. В корне должны лежать `settings.gradle.kts`, `build.gradle.kts` и папка `app`.
3. Открой вкладку **Actions** и запусти **Build Android APK**.
4. После успешной сборки открой запуск workflow и скачай артефакт **AI-Fitting-Room-debug**. Внутри будет `app-debug.apk`.

В этой рабочей среде отсутствуют Android SDK и Gradle, поэтому готовый APK здесь не был собран. Workflow соберёт его на GitHub-hosted runner.
